## Acceptance
- A delimited file is read into headers and rows
- The first line is treated as headers, never as data
- A cell that cannot be read as a number in a numeric column throws, carrying its line number
- An empty file gives an empty row list rather than throwing
- The parser returns values and never prints

## Constraints
- Do not touch src/core or src/format
- Do not add a dependency to package.json
- Do not decide how an error is presented to the operator — that belongs to the CLI layer
