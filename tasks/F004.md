## Acceptance
- The tool takes exactly one argument, the path of the file to summarise
- A missing or extra argument exits non-zero with a usage line on standard error
- A bad cell exits non-zero with the offending line number on standard error
- A successful run prints the table on standard output and exits zero

## Constraints
- This is the only module allowed to touch process.argv, process.exit or the console
- Do not modify src/report, src/core or src/parse
